# 🌍 TravelMania

TravelMania is a modern **travel itinerary planner** built with React that enables users to visually create, customize, and manage their travel plans through an interactive workflow interface. Inspired by node-based editors like n8n, it transforms traditional itinerary planning into an engaging and intuitive experience.

---

## ✨ Features

- 🗺️ Interactive itinerary builder using React Flow
- 🏨 Create and organize hotels, tourist spots, and travel routes
- 📍 Visual node-based travel planning
- 🎨 Modern and responsive user interface
- 🌙 Dark/Light mode support
- 🧭 Explore page with pre-built travel itineraries
- ✏️ Customize existing itineraries
- 📱 Responsive design for different screen sizes
- 🚀 Smooth animations and interactive homepage

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/<your-username>/TravelMania.git
```

### Navigate to the frontend

```bash
cd TravelMania/frontend
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
